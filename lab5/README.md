# Лабораторная работа №5. Основы коллективной работы в среде 1С:Предприятие 8

Дисциплина «Коллективная разработка приложений», Московский университет «Синергия».
Выполнил: Лисичкин Борис Олегович, группа ВБИо-402рсоб.

В учебной версии платформы 1С:Предприятие 8.3 работа с хранилищем конфигурации не поддерживается,
поэтому коллективная разработка организована через Git: конфигурация хранится в репозитории в виде XML-файлов
(выгрузка «Конфигурация → Выгрузить конфигурацию в файлы»), каждый разработчик работает в своей файловой базе и своей ветке,
изменения попадают в main через pull request, конфликты разрешаются при слиянии.

## Структура

```
src/          конфигурация 1С в XML (формат выгрузки 2.20, платформа 8.3.27)
tools/        Build-Base.ps1 (собрать базу из XML), Dump-Base.ps1 (выгрузить базу в XML), Save-Shot.ps1 (снимок окна)
screenshots/  снимки экрана для отчёта
```

## Как собрать базу

```powershell
.\tools\Build-Base.ps1 -Base C:\lab5\bases\dev1
```
