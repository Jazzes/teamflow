# Лабораторная работа №5. Основы коллективной работы в среде 1С:Предприятие 8

Дисциплина «Коллективная разработка приложений», Московский университет «Синергия».
Выполнил: Лисичкин Борис Олегович, группа ВБИо-402рсоб.

В учебной версии платформы 1С:Предприятие 8.3 (8.3.27.1508) хранилище конфигурации недоступно: в меню
«Конфигурация» нет пункта «Хранилище» (см. `screenshots/01-menu-konfiguraciya.png`). Поэтому коллективная
разработка организована по той же схеме, что и в 1С:EDT: конфигурация хранится в Git в виде XML-файлов
(«Конфигурация → Выгрузить конфигурацию в файлы»), у каждого разработчика своя файловая база и своя ветка,
изменения попадают в `main` только через pull request, конфликты разрешаются при слиянии.

## Роли

| Участник | Задача | Ветка | Pull request |
|---|---|---|---|
| Владелец репозитория | исходная пустая конфигурация, скрипты, защита ветки `main` | `feature/lab5-init` | #2 |
| Разработчик 1 | справочник «Клиенты» (ФИО, Телефон, EMail), подсистема | `feature/lab5-dev1-catalog` | #3 |

| Разработчик 3 | поиск клиентов по ФИО | `feature/lab5-dev3-search` | #5 |
| Разработчик 1 | конфликтное изменение структуры справочника | `feature/lab5-dev1-structure` | #6 |
| Разработчик 3 | исправление ошибки, найденной при совместном тестировании | `fix/lab5-dev3-search-filter` | #7 |

Ветка `main` защищена правилом GitHub: изменения попадают в неё через pull request после успешной обязательной проверки `lab4-tests`.

## Конфликт

Разработчик 1 (PR #6) изменил индексирование реквизита ФИО на `IndexWithAdditionalOrder`, а разработчик 3 в своей
ветке поставил `Index`. После слияния PR #6 команда `git merge main` в ветке разработчика 3 дала конфликт
в `src/Catalogs/Клиенты.xml` и `src/ConfigDumpInfo.xml`. В `Клиенты.xml` вручную оставлен вариант
`IndexWithAdditionalOrder`, `ConfigDumpInfo.xml` пересобран: база собрана из XML и снова выгружена (коммит 79dde5c).

## Структура

```
src/          конфигурация 1С в XML (формат выгрузки 2.20, платформа 8.3.27)
tools/        Build-Base.ps1 (собрать базу из XML), Dump-Base.ps1 (выгрузить базу в XML), Save-Shot.ps1 (снимок окна)
screenshots/  снимки экрана для отчёта
```

## Как собрать базу

```powershell
.\tools\Build-Base.ps1 -Base C:\lab5\bases\dev1
```

После изменений в конфигураторе выгрузить базу обратно в XML и закоммитить:

```powershell
.\tools\Dump-Base.ps1 -Base C:\lab5\bases\dev1
git add src
git commit -m "..."
```
